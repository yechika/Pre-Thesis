        * Binary × categorical → chi-square + Cramér's V

5.1 Kesimpulan (jawab 3 RQ)

RQ1 (perbandingan model):
    - Sentimen fine-tuned: RoBERTa terbaik F1-macro 0.222 [0.197, 0.253], tapi
      semua 3 model CI tumpang tindih (tidak signifikan beda statistik).
    - Detoxify zero-shot accuracy 0.42 lebih tinggi dari fine-tuned 0.39.
    - Toksisitas: Detoxify pretrained terbaik F1-micro 0.152, F1-macro 0.081.
    - Implikasi: Specialist pretrained > generalist fine-tuned untuk domain
      Dota chat. Domain shift dari TweetEval/Jigsaw substansial.

RQ2 (tren temporal):
    - Sentimen menurun (Mann-Kendall tau=-0.58, p<1e-16).
    - Pandemi 2020-03 = breakpoint struktural terkuat (Chow break di 4/4 metric).
    - Toxicity intensification: frekuensi turun (-0.50) tapi severity naik (+0.32).
    - Post-DPC era: sportsmanship drop signifikan.
    - Implikasi: Komunitas dewasa secara umum, tapi extreme tail makin parah.
      Pandemi disrupt komunikasi profesional.

RQ3 (faktor kontekstual):
    - Semua 5 faktor signifikan setelah BH-FDR (10 uji statistik).
    - Terkuat: duration × max_toxicity ρ=-0.080 (robust per-match ρ=-0.147).
    - Kalah → toxic (Mann-Whitney r=0.060, hipotesis H1 valid).
    - Tier × toxicity NS di per-match level (clustering artifact, hapus klaim utama).
    - Implikasi: Match singkat (early-stomp) + tim kalah = high-risk untuk
      moderasi otomatis. Sistem moderasi prioritaskan target ini.


5.2 Saran (Source: CHAPTER4_SUMMARY.md §4.5.3)

    - Multilingual analysis: 274.087 baris non-Inggris (Russia/CN/SEA)
      dieksklusi. Replikasi dengan XLM-RoBERTa multilingual → cakupan +14% data.
    - Multi-modal: voice chat (transcribe) + emote + chat teks. Voice signal
      kemungkinan paling kaya untuk emosi.
    - Causality experiments: random assignment communication ban duration.
      Korelasi → kausalitas.
    - Crowdsource anotasi 50.000+ in-domain Dota chat. Estimasi naik F1-macro
      sentimen dari 0.22 ke 0.55-0.65 berbasis literature.
    - Per-player longitudinal: track toxicity/sentiment per pemain sepanjang
      karir (account_id available).
    - Toxicity intensification investigation: kenapa frekuensi turun tapi
      severity naik? Apakah Valve communication ban hanya filter low-severity?
